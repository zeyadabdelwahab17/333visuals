# 333 Visuals — portfolio site

- `index.html` — the website (design + logic). You don't need to edit it.
- `works.json` — the list of videos. Edited through the admin panel.
- `.pages.yml` — settings for the admin panel (Pages CMS).
- `media/` — uploaded video files and thumbnails.

## Edit videos
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open this repository → **Videos**.
3. Add, edit, reorder, hide or delete videos → **Save**.
4. The live site updates by itself in about a minute.

Big or long videos: upload to Vimeo (public) and paste the link.
Short clips and before/after pairs: upload the MP4 directly (under 25 MB each).
